# スコアリング

本ツールは、AP/BSSIDそのものの無線状態を表す「品質スコア」と、今このPCが接続先として選ぶ優先度を表す「選択スコア」を分けて扱う。いずれも`score_access_point`が同じ入力から計算し、GUIでは両方を表示する。CLIの`rank`は互換性維持のため従来どおり選択スコアだけを`score=`として表示する。

## 品質スコア（0～73点）

品質スコアは次の3項の合計である。接続履歴、直近失敗、現在接続中かどうかは含めない。

| 要素 | 最大 | 計算 |
|---|---:|---|
| 信号 | 45 | RSSIを-90～-50 dBmで0～1へ線形正規化した32点と、Windows link quality（0～100%）を線形換算した13点の和 |
| BSS Load | 20 | `20 * (1 - Channel Utilization / 255)` |
| 同一チャネル干渉 | 8 | `8 / (1 + 0.35 * 同一チャネル近隣BSS数)` |

BSS Load IEが広告されない場合、Channel Utilizationを推測せず、中立値10/20点を置く。Station Countは関連付け端末数であって通信量ではないため、表示には使うが得点へ直接加えない。同一チャネル近隣数は対象SSIDだけでなく、同じスキャンで観測した他SSIDも含める。

## 選択スコア（0～100点）

選択スコアは既存のAPスコアと同じであり、次の式を最後に0～100へクランプする。

`品質スコア + 接続履歴点 - 直近失敗ペナルティ + 現在APボーナス`

| 要素 | 点数 | 意味 |
|---|---:|---|
| 接続履歴 | 0～17 | 本ツールが記録した接続成否。試行なしは中立8.5点 |
| 直近失敗 | 0～-21 | 1回あたり既定7点、最大3回分 |
| 現在AP | 既定+8 | 小差で頻繁に切り替わることを抑えるヒステリシス |

接続履歴に試行がある場合は、成功率をそのまま使わず`(成功数 + 1) / (試行数 + 2)`のLaplace平滑化を行い、17倍する。少数試行の0%や100%を過信せず、観測が増えるほど実績へ近づけるためである。履歴なしの8.5点、BSS Load欠損時の10点はいずれも「測定できなかった値を捏造する」のではなく、欠損だけで極端な有利・不利を作らない中立値である。

順位が同点の場合は、現在接続中のAP、RSSIの高いAP、正規化BSSIDの辞書順で決定する。選択スコアの式、クランプ、理由文字列は従来互換のままである。
